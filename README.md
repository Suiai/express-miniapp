# 私人菜谱小程序

基于微信小程序 + 云开发的**私人菜谱 + 团队协作**应用。

- **私人菜谱**：每个人只能看到自己维护的菜谱，互相不可见
- **团队协作**：创建团队、邀请码邀请成员，团队内成员可共同维护同一套菜谱
- 菜谱支持上传照片、名称、描述、价格；详情页可查看/编辑/删除

## 功能

- 我的菜谱 / 团队菜谱 双模式切换
- 私人菜谱：仅创建者本人可见、可编辑
- 团队管理：创建团队、邀请码加入、成员列表、移除成员、退出/解散
- 团队菜谱：全体成员可共同查看、添加、编辑、删除
- 点餐通知（可选）：详情页确认点餐 → 微信订阅消息回执给点餐用户
- 所有数据读写均通过云函数（云端校验权限，前端无数据库直接权限）

## 数据模型

| 集合 | 说明 |
|------|------|
| `users` | 用户档案，`_id` = openid（首次进入自动注册） |
| `recipes` | 菜谱：`scope`（personal/team）、`ownerOpenid`、`teamId` |
| `teams` | 团队：名称、描述、创建者、邀请码 |
| `teamMembers` | 成员关系：teamId + openid + role（owner/member） |
| `orders` | 点餐订单（可选功能） |

## 云开发部署步骤

> 所有集合权限请保持默认「**仅管理端可读写**」——前端一律通过云函数读写，不需要给前端开放数据库权限。

### 第 1 步：确认云开发已开通

1. 用微信开发者工具打开 `D:\WorkBuddy\express-miniapp`
2. 点击工具栏「云开发」按钮，确认已开通并有一个可用环境
3. 如提示未开通，按引导开通即可（免费额度足够个人使用）

### 第 2 步：部署云函数（4 个）

右键以下每个云函数目录 →「上传并部署：云端安装依赖」：

1. `cloudfunctions/user` — 用户注册
2. `cloudfunctions/recipe` — 菜谱 CRUD（核心）
3. `cloudfunctions/team` — 团队管理
4. `cloudfunctions/sendOrderNotify` — 点餐通知（可选，跳过则详情页点餐不可用）

> 部署前先在左侧资源管理器右键 `cloudfunctions` 文件夹 →「当前环境」→ 选中你的云环境，否则上传会报"请选择一个云环境"。

### 第 3 步：运行 initDB 初始化

1. 部署 `cloudfunctions/initDB`
2. 云开发控制台 → 云函数 → `initDB` →「测试」运行一次
3. 返回 `{ "success": true, "results": {...}, "migrated": N }` 即成功
   - 自动创建 `users / recipes / teams / teamMembers / orders` 5 个集合
   - 自动把旧版点餐数据（foods 中带 `_openid` 的记录）迁移为个人菜谱

### 第 4 步：验证

1. 首页「我的菜谱」为空 → 点右下角 + 添加一道菜谱 → 仅你自己可见
2. 点右上角「团队管理」→ 创建团队 → 复制邀请码
3. 另一微信号（或预览扫码的另一设备）→「加入团队」输入邀请码
4. 两个账号都能看到并共同维护该团队的菜谱；互相看不到对方的私人菜谱

## 订阅消息配置（可选）

详情页「确认点餐」会给**点餐用户本人**发送微信订阅消息回执。配置方法：

1. 登录 [微信公众平台](https://mp.weixin.qq.com) →「功能」→「订阅消息」→「公共模板库」
2. 选用包含「名称」「描述」「时间」字段的模板，记下模板 ID
3. 填入两处（需一致）：
   - `app.js` → `subscribeTemplateId`
   - `cloudfunctions/sendOrderNotify/index.js` → `TEMPLATE_ID`
4. 按模板实际字段名调整云函数中 `data` 的 key（如 `thing1`/`thing2`/`time5`）
5. 重新部署 `sendOrderNotify`，用「预览」扫码在**真机**上测试（模拟器不支持订阅消息弹窗）

## 常见问题

### Q: 首页提示「云函数未部署」？
A: 按顺序：① 右键 `cloudfunctions` 文件夹选「当前环境」；② 部署 `user`/`recipe`/`team` 三个云函数；③ 部署并运行 `initDB`。

### Q: 团队菜谱不显示？
A: 确认你已加入该团队（团队管理页可见），且列表顶部选中了正确的团队。

### Q: 为什么不能直接改别人的私人菜谱？
A: 这是产品设计——私人菜谱仅创建者可见可改；要协作请使用团队菜谱，把对方拉进团队。

### Q: 点餐后收不到微信通知？
A: 按顺序排查：模板 ID 是否两处一致、`sendOrderNotify` 是否已部署、字段 key 是否与模板匹配、是否在真机上测试。
