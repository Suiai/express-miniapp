# 美味点餐小程序

一个基于微信小程序的点餐应用，支持上传菜品照片、名称、描述，确认点餐后发送微信订阅消息通知。

## 功能

- 菜品列表浏览（带照片、名称、描述、价格）
- 添加新菜品（拍照/相册上传照片）
- 菜品详情查看
- 确认点餐 → 微信订阅消息通知
- 本地存储持久化

```
├── components/
│   └── food-item/                   # 菜品卡片组件

│   └── sendOrderNotify/             # 发送点餐通知云函数
├── utils/util.js                    # 工具函数
└── assets/                          # 图标资源
```

## 快速开始

### 1. 导入项目

用微信开发者工具打开 `D:\WorkBuddy\express-miniapp` 目录。

### 2. 基础功能（无需云开发）

菜品浏览、添加、查看详情等功能开箱即用，数据存储在本地。

### 3. 配置微信通知（需云开发）

点餐通知使用微信「订阅消息」能力，需要以下步骤：

#### 步骤一：开通云开发

在微信开发者工具中点击「云开发」→「开通」，创建一个云环境。

#### 步骤二：创建订阅消息模板

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 进入「功能」→「订阅消息」→「公共模板库」
3. 选择一个包含「名称」「描述」「时间」字段的模板（或自行组合）
4. 记下模板 ID

#### 步骤三：配置模板 ID

打开 `app.js`，将 `subscribeTemplateId` 替换为你的模板 ID：

```js
globalData: {
  subscribeTemplateId: '你的模板ID'
}
```

#### 步骤四：部署云函数

1. 在开发者工具中右键 `cloudfunctions/sendOrderNotify` 文件夹
2. 选择「上传并部署：云端安装依赖」
3. 等待部署完成

#### 步骤五：修改云函数模板字段

打开 `cloudfunctions/sendOrderNotify/index.js`，根据你的模板实际字段修改 `data` 中的 key（如 `thing1`、`thing2`、`time3`）。

### 4. 通知效果

完成以上配置后，点击「确认点餐」→ 微信将收到订阅消息通知，包含菜品名称、描述和下单时间。

> 如果未开通云开发，点餐时会显示模拟通知弹窗，不影响其他功能体验。
